# 同梱しているソフトウェアとモデルのライセンス（Third-Party Notices）

VoiceDock for Mac（`LICENSE` のとおり Apache License 2.0）は、次のソフトウェアとモデルを `VoiceDock.app` に同梱しています。
それぞれの著作権表示とライセンス文を、配布元のものからそのまま載せます。
このファイルは `VoiceDock.app/Contents/Resources/THIRD_PARTY_NOTICES.md` にも同梱されています。

VoiceDock for Mac bundles the third-party software and models listed below.
Their copyright notices and license texts are reproduced verbatim from the upstream sources.

| 同梱物 | 使っている場所 | 版 | ライセンス |
|---|---|---|---|
| whisper.cpp | `Contents/Helpers/whisper-cli` | v1.9.4（`927cfce`） | MIT |
| llama.cpp | `Contents/Helpers/llama-server` | b11033（`8ed1a55`） | MIT |
| llama.cpp が取り込んでいる部品（llamafile の sgemm など） | `Contents/Helpers/llama-server` | llama.cpp と同じ | MIT・BSD-2-Clause・パブリックドメイン（下の一覧） |
| ggml の中の YaRN の RoPE | `Contents/Helpers/whisper-cli`・`Contents/Helpers/llama-server` | whisper.cpp・llama.cpp と同じ | MIT |
| argmax-oss-swift | `Contents/Helpers/argmax-cli` | v1.1.0（`1e2a163`） | MIT（一部 Apache-2.0） |
| swift-argument-parser | `Contents/Helpers/argmax-cli` | 1.7.0 | Apache-2.0（Runtime Library Exception 付き） |
| GRDB.swift | `Contents/MacOS/VoiceDock` | 7.11.1 | MIT |
| Yams（LibYAML を含む） | `Contents/MacOS/VoiceDock` | 6.2.2 | MIT |
| 話者分離のモデル（pyannote community-1 の Core ML 版） | `Contents/Resources/SpeakerModels/` | `556fc52` | CC-BY-4.0 |

アプリの中から利用者がダウンロードするモデル（Whisper・VAD・LLM）は同梱していません。それぞれの配布元のライセンスに従います（README の「ライセンス」）。
