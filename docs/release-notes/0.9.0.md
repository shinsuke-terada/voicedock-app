# VoiceDock for Mac 0.9.0

DJI Mic 3 の録音を Mac につなぐだけで取り込み、文字起こし（whisper.cpp）と要約（llama.cpp）をして Obsidian の Vault にノートを書く、メニューバーのアプリの最初の配布版です。
処理はすべて Mac の中で行い、録音と文字を外へ出しません。

v1.0 の前の版です。**元音声の削除（既定は無効）は、実機での 1 日運用の確認（E2E-06・G-4・G-5）が済んでいないため、試験的な機能として扱ってください。**

## できること
- デバイスをつなぐと取り込み、文字起こしして、日ごとの Raw ノートと Daily ノート（要約・要点・タスクなど）を書く
- 取り込むデバイスの名前は既定で `VOICEDOCK`（Finder でデバイスの名前を変えてから使う）
- 話者分離（既定はオフ）、要約プロンプトの編集、データの初期化（「詳細・診断」）
- 元音声の削除（三重ロック。既定は無効）

## 入れ方
1. `VoiceDock-0.9.0.dmg` を開き、`VoiceDock` を `Applications` へドラッグする
2. 起動したらパネルの「はじめに」を上から済ませる（Vault・Whisper モデル・LLM・ログイン項目）

詳しくは README の「インストール」を見てください。

## 既知の制約
- 送信機 2 台の同時接続は実機で確かめていない（RK-07）
- 取り込みの後にデバイスの名前を変えると、残っている録音をもう一度取り込んで「重複」になる（RK-28。変えるなら先にデータの初期化）
- 使い始めた後にタイムゾーンを変えない（RK-32）

## 動作環境
macOS 15 以降、Apple シリコン（arm64）の Mac
