# VoiceDock 1.0.1

DJI Mic 3 の録音を Mac につなぐだけで取り込み、文字起こし（whisper.cpp）と要約（llama.cpp）をして Obsidian の Vault にノートを書く、メニューバーのアプリです。処理はすべて Mac の中で行い、録音と文字を外へ出しません。

## 入れ方
1. `VoiceDock-1.0.1.dmg` を開き、`VoiceDock` を `Applications` へドラッグする
2. 初めてデバイスを挿したときの許可のダイアログで「許可」を押す
3. 詳しくは README を参照

## 変わったこと
- 文字起こしの Whisper の既定のモデルを `large-v3-turbo-q5_0`（574 MB）から `large-v3-turbo-q8_0`（874 MB）に替えた。量子化による劣化が少ない。**新しく入れたときの既定だけが変わる**
- 1.0.0 から入れ替えた場合は、設定（`config.json`）は q5_0 のままで、そのまま動き続ける。q8_0 に切り替えるには、`~/Library/Application Support/VoiceDock/config.json` の `transcription.whisperModelID` を `"large-v3-turbo-q8_0"` に書き換えて保存し、パネルの「設定を読み直す」を押してから、パネルのモデルの欄で Whisper を入手する。入手するまで文字起こしは始まらない。古い `models/whisper/ggml-large-v3-turbo-q5_0.bin` は要らなければ手で消してよい
- 1.0.1 を入れた後で 1.0.0 に戻すときは、先に `whisperModelID` を `"large-v3-turbo-q5_0"` に戻す（1.0.0 のカタログには q8_0 が無く、設定エラーになる）
- 削除を有効にしている場合は、入れ替えた後にパネルに「削除モジュールの更新が必要です」が出る。有効化の操作をもう一度通すと 1.0.1 の削除モジュールに置き換わる
